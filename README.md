# Crypto Toolkit - 纯 React 加密工具包

一个功能强大的纯 React 加密解密工具集，所有操作均在客户端浏览器完成，确保数据安全。

## 项目简介

**Crypto Toolkit** 是一个基于 React + Vite + Tailwind CSS 构建的加密工具集，提供多种加密、解密和哈希算法，所有加密逻辑均在客户端完成，确保数据安全。

### 核心功能

- **Base64 编码/解码** - 用于处理二进制文本化
- **MD5 哈希** - 生成固定的 32 位 16 进制字符串
- **AES 加密/解密** - 高级加密标准，支持密钥和偏移向量配置
- **SHA-256 哈希** - 广泛用于安全验证和数字签名
- **DES 加密/解密** - 数据加密标准，适用于特定旧系统

## 技术栈

- **框架**: React 18
- **构建工具**: Vite 8.0.0-beta.15
- **CSS 框架**: Tailwind CSS 3.4.19
- **加密库**: CryptoJS 4.2.0 (通过 CDN 动态加载)
- **字体**: 思源黑体 (Noto Sans SC)

## 项目特点

- ✅ **隐私至上** - 所有加密逻辑均在客户端完成，绝不上传数据
- ✅ **现代化界面** - 响应式设计，支持桌面和移动设备
- ✅ **多算法支持** - 集成多种常用加密和哈希算法
- ✅ **实时反馈** - 零延迟操作，即时显示处理结果
- ✅ **结果复制** - 一键复制处理结果到剪贴板
- ✅ **动态加载** - 按需加载 CryptoJS 库，优化首屏加载速度
- ✅ **中文友好** - 使用思源黑体，提升中文显示效果

## 快速开始

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm run dev
```

开发服务器启动后，可通过以下地址访问：
- http://localhost:5173/

### 构建项目

```bash
pnpm run build
```

构建产物将生成到 `dist` 目录。

## 使用指南

1. **选择工具** - 从左侧导航栏选择需要使用的加密工具
2. **输入数据** - 在输入框中填写需要处理的内容
3. **配置参数** - 对于加密算法，可设置密钥和偏移向量
4. **执行操作** - 点击相应的按钮执行编码/解码/加密/解密/哈希操作
5. **查看结果** - 在输出区域查看处理结果
6. **复制结果** - 点击复制按钮将结果复制到剪贴板

## 技术实现

### 加密逻辑

- 使用 CryptoJS 库实现各种加密算法
- 所有操作均在客户端浏览器中完成，数据不离开本地
- 支持错误处理和状态管理

### 界面设计

- 使用 Tailwind CSS 构建现代化响应式界面
- 采用卡片式布局，清晰分隔不同功能区域
- 支持暗色模式和亮色模式
- 响应式设计，适配不同屏幕尺寸

### 性能优化

- 动态加载 CryptoJS 库，减少首屏加载时间
- 使用 React useMemo 优化计算性能
- 按需渲染，减少不必要的重渲染

## 注意事项

1. **数据安全** - 虽然所有操作在客户端完成，但仍建议不要在公共设备上处理敏感信息
2. **密钥管理** - 对于加密操作，请妥善保管密钥和偏移向量
3. **算法选择** - 根据具体使用场景选择合适的加密算法
4. **依赖管理** - 项目使用 pnpm 作为包管理器
